# 賽程表

公開網站：https://ytolemop.github.io/ranking/

2～128 人單淘汰賽程，包含隨機抽籤、第一輪長籤、點選晉級、三四名決定賽、復原及 JSON 備份。

賽程由下往上晉級，卡片維持基本大小。使用滑鼠拖曳空白處、觸控滑動、捲軸或方向鍵移動，按「回到中央」回到冠軍賽。

「待打對局」列出雙方已確定、尚未選出勝者的場次，排除輪空及已完成對局。點選清單或「找下一場」即可定位並標示對局。

## 資料模式

- **本機模式**：`config.js` 未設定時，沿用瀏覽器儲存，每個裝置各自操作，不會同步。
- **共用模式**：設定 Supabase 後，訪客只能讀取；指定管理者以 Email 一次性連結登入後，才可修改共用賽程。公開頁面每 5 秒更新。

啟用步驟請見 [SETUP.md](SETUP.md)。資料庫權限與儲存函式在 [schema.sql](schema.sql)。不要把 service_role、secret key、資料庫密碼或帳號 token 上傳至 repo。

## GitHub Pages

將網站檔案放在 main 分支根目錄，在 Settings → Pages 選擇 main 與 / (root)。沒有編譯步驟。共用模式需有 HTTPS 及對應的 Supabase URL 設定。

原有本機賽程不會自動上傳；管理者首次登入後可匯入備份或選擇「匯入本機進度」。
