# 晉級之路

無須安裝或後端的個人單淘汰賽程表，支援 2～128 人、編號選手、隨機抽籤、平均配置輪空長籤、點選晉級與三四名決定賽。

## 開始使用

直接開啟 index.html 即可使用；正式使用建議放到 GitHub Pages，以固定網址保留瀏覽器儲存空間。

1. 輸入賽事名稱與人數，按「抽籤／建立賽程」。
2. 點選一場比賽的勝者，自動帶入下一輪。長籤自動晉級。
3. 四強結束後，可選擇冠軍賽及季軍賽的勝者。少於 4 人不設季軍賽。
4. 誤按可「復原」。改選前輪勝者會清除受影響的後續賽果。
5. 「匯出備份」保留抽籤及結果；換裝置用「匯入」還原。
6. 「列印 / PDF」可輸出紙本或 PDF；大賽程請選橫向、大紙張及縮放。

## 放到 GitHub Pages

1. 在 GitHub 建立儲存庫，例如 tournament。免費帳戶使用 Pages 通常需公開儲存庫。
2. 將本資料夾的 index.html、style.css、bracket.js、app.js 與 .nojekyll 上傳到儲存庫根目錄。
3. 到儲存庫 Settings → Pages → Build and deployment，選 Deploy from a branch。
4. 選 main 分支與 / (root)，儲存。等 GitHub 顯示網址即可使用。

本網站沒有帳號或伺服器資料庫。進度只存目前瀏覽器，不會同步到 GitHub、其他裝置或其他使用者。清除瀏覽資料會刪除進度，請匯出備份。GitHub Pages 網址本身是公開的，但只有使用者在自己瀏覽器操作的賽事資料。

抽籤會將選手順序、長籤位置隨機化；輪空只配置於第一輪，且不會出現輪空對輪空。沒有種子選手規則。
